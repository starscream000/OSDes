## About this project

OSDes is the design prototype for a Metro-inspired operating system
interface that should eventually run on desktops, laptops, phones, and other
screens. It is a Qt Design Studio project written in QML (Qt 6.8). At this
stage it is an app window that shows the interface; it does not yet manage
other programs' windows.

## How to build, run, and test

- Run: open `OS.qmlproject` in Qt Design Studio and press Run (Ctrl+R). The
  owner does this; a worker usually cannot see the running interface.
- Check: run `qmllint -I .` on every QML file you changed. It is usually not
  on the PATH. On the owner's Windows machine it ships with Qt Design Studio
  at `C:/Qt/Tools/QtDesignStudio/qt6_design_studio_reduced_version/bin/`,
  next to `qmltestrunner`. If you cannot find it, say so in your report
  instead of skipping silently.
- Build from the command line: not set up yet.
- Tests: none yet.

## Merging

Standing order from the owner: when the master's review verdict is
**Approve**, the master merges the pull request straight away and then
tells the owner. It does not ask first. With a verdict of **Changes
requested**, nothing is merged. Workers still never merge.

## Keeping the README current

`README.md` states the owner's vision in plain words and what exists
today. The master updates it, as a planning file, in the same commit as any
change to the vision, a principle, a milestone, or what is built. That
means after every merge and after every design decision. Workers do not
edit it.

## Project rules

- **`.ui.qml` files stay declarative.** They must open in Qt Design Studio's
  visual editor, so they contain no JavaScript functions or `{ }` code
  blocks. Property bindings are fine. Put logic in plain `.qml` components
  and use those from the `.ui.qml` file.
- **No hard-coded look.** Colours, sizes, spacing, and fonts come from the
  shared theme in the `OS` module. A component never contains a literal
  colour or pixel size that the theme should own.
- **Register new files.** A new QML file in `OS/` goes into `OS/qmldir` and
  the `QML_FILES` list in `OS/CMakeLists.txt`. A new QML file in
  `OSContent/` goes into the `QML_FILES` list in `OSContent/CMakeLists.txt`.
  Those two lists are the only parts of the generated CMake files you may
  touch.
- **Our own assets only.** The design follows Metro's principles (flat
  colour, sharp rectangles, strong typography, content before decoration).
  Do not copy Microsoft's icons, images, logos, or fonts into the project.
- **One component per file**, named in `UpperCamelCase.qml`, with `id`s in
  `lowerCamelCase`.
- **Text goes through `qsTr()`** so it can be translated later.
